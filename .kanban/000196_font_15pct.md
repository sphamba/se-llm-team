# Summary

Every font-size in the served webui CSS grows 15%, each result rounded to an integer px. All sizes live in the single CSS block in src/webui/page.ts.

# Specs

## Mapping (size x 1.15, rounded half up)
- 10px -> 12px (4 occurrences)
- 11px -> 13px (1)
- 12px -> 14px (11)
- 13px -> 15px (4)
- 15px -> 17px (1)
- 16px -> 18px (1)

## Rules
- Replace each font-size declaration per the mapping; nothing else in the CSS changes.
- The #147 Inter/monospace stacks, the #175 pre-wrap rules, the #194 motion rules (closing, clip trick) and every other declaration stay untouched.
- No rem/em conversions; the sizes stay px.

## Tests
- The five suites stay green; add or extend one CSS assert that no pre-change sizes remain in the served page (e.g. the page contains font-size: 14px and no font-size: 12px).
- Live check: the board, the task modal, and the log pane read comfortably larger; nothing overlaps or wraps unexpectedly.
