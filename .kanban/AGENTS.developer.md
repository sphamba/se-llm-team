# developer: append project-specific guidance for this role below (e.g. how to run the project, how to live-test) so future agents of your kind start faster.

- Tests are plain assert-style ESM scripts, no framework: `node tests/<file>.test.ts` per file, `npm test` for the suite.
- To intercept src module internals from a test (fs calls, hooks inside a function), spawn a child with `--require <preload.cjs>`: patches to `require("node:fs")` propagate to ESM named imports only when installed before the first import; an in-process patch never does (facade bindings resolve at first import).
- Deterministic interleaving control in orchestrator tests: drive `rescan(root, cfg)` and `poll(root, stallMinutes)` directly (import `rescan` from `../src/orchestrator/pipeline.ts`, `poll`/`loadConfig` from the facade; temp HOME via `mkdtempSync` + `loadConfig`; `cfg.agent = <stub>`), instead of relying on daemon timing races. A stub that `Atomics.wait`s ~1s keeps a spawned agent alive across the next synchronous call. Temp scripts outside a package need the `.mjs` extension; when a fixture file must keep a specific name (e.g. `orchestrator.ts` for cmdline matching), drop a `package.json` with `{"type": "module"}` next to it instead, else node loads the `.ts` as CJS and it dies at the first import.
- To tell a flake from a regression: `git stash push`, run the failing suite at HEAD, `git stash pop`. Fix test-race flakes at the root cause: gate the fixture write against the racing machinery (e.g. an openQuestions-backed task is never promoted).
- Idle-gate tests: drive `promoteBacklog(root, listAll(root), windowMinutes)` directly and age a file with `utimesSync(path, new Date(Date.now() - 10_000), ...)` (0.05 min window = 3 s). The quiet window is board-wide, but only over real task files: `ROLE_NOTES_RE` names (`AGENTS*.md`) do not count (#212).
- In a task worktree, `.kanban` is a symlink to the main checkout's board: writing SPECS.md or AGENTS.md here edits the main checkout file, and git in the worktree reports `.kanban/...` as "beyond a symbolic link" (never stage or commit those). The daemon commits board changes itself.
- Comments in src avoid em/en-dashes; use colons, commas, parentheses, hyphens.
- Live webui check (reusable recipe, #205/#206): temp root `/tmp/<name>/root` with `.kanban/000001_probe.md` (long body) and `.kanban/se-llm-team.json` `{"webUi":{"enabled":true,"host":"127.0.0.1","port":4321}}` (project config overrides the global port), daemon `node src/orchestrator.ts --root <tmp> --rescan-seconds 30 --poll-minutes 5 &` (the CLI entry is src/orchestrator.ts, src/orchestrator/main.ts has no self-call and exits silently), then a Playwright script against `http://127.0.0.1:4321/` (playwright at `/home/phamba/repos/paseo/node_modules/playwright/index.mjs`, template `/tmp/t205lt/check.mjs`). Run that daemon with an isolated HOME (`HOME=/tmp/<name>/home`): the production daemon holds the global hub lock (`~/.pi/agent/se-llm-team-hub.lock`), so under the real HOME the probe logs "hub lock held by another daemon, standing down" and serves no UI. Never run a live-check daemon without the per-root port override: it reads the global config and binds the production webui port (global config: 4242 on 0.0.0.0, held by a long-running daemon under the real HOME; never signal that one). Health-probe with `curl -sf http://127.0.0.1:4321/` (`/api/board` is 404 in this build, only `GET /` serves). Kill it by the pid listening on the port (`ss -ltnp | grep :4321`), after checking `/proc/<pid>/cmdline` contains `--root /tmp/<name>/root`; `$!` after `nohup ... &` can be a wrapper subshell, and `pkill -f "<pattern>"` matches your own bash -c command line and kills the shell (exit 143).
- Playwright and the popup: `#modal` is `position: fixed; inset: 0; z-index: 3`, so while a popup is open every card click is intercepted (`<div id="modal"> intercepts pointer events`). Close with Escape and wait for `#modal.hidden` before clicking the next card, or call `window.openTask(file)` via `page.evaluate` to bypass hit-testing.
- Modal scroll gotcha: `#modal.hidden` is `display: none`, so a `scrollTop` write on `#m-box` while hidden is discarded and the browser restores the stored offset on the next show; any open-time scroll reset must run after the un-hide (#209).
- Seed the live-check probe task in state `done`: a `backlog` task auto-promotes to `to-do` at the first sweep and the daemon spawns a real agent for it. `done` renders the popup and spawns nothing.
- Live-test artifacts: daemon log `.kanban/.logs/orchestrator.log` (also daemon stdout), PM reports `.kanban/.reports/*.md` (one per sweep with a done transition, oldest first by name).
- Large argv elements: the kernel rejects a single argument over 131,072 bytes with E2BIG (MAX_ARG_STRLEN); node spawn reports it as a child 'error' event and the child never starts (#213). The AGENTS.md injection cap (PROJECT_PROMPT_CAP, src/orchestrator/spawn.ts) is 131,000, and the at-cap boundary is covered by a real stub spawn in tests/orchestrator.test.ts (#214).
- Read-only HOME mounts: on this machine ~/.pi and ~/.config are read-only bind mounts, so any test or close() flush that touches the real user config dir crashes (or, on normal machines, pollutes it). Close in-process hubs before restoring the real HOME, and keep global-state tests on fixture HOMEs (#215).
- process.env.X = undefined sets the env to the string "undefined" in node; delete process.env.X instead when restoring an unset variable, else later code resolves paths like undefined/se-llm-team and litters the cwd (#215).
- Neutral shared paths (#215): the global config, hub registry and hub lock live at $XDG_CONFIG_HOME/se-llm-team/ (else ~/.config/se-llm-team/), with the legacy ~/.pi/agent paths as read-only fallbacks; every temp-HOME test env must also set or delete XDG_CONFIG_HOME, since the real environment may set it and leak the production config into tests.
