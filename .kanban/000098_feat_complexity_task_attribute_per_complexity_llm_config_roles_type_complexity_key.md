# Summary
Tasks gain a complexity attribute (simple/moderate/complex, default moderate, updatable later), and the LLM config gains per-complexity overrides: roles.<type>.<complexity>.<key> beats the role default (roles.<type>.<key>), which beats the global value. Following #97, the reviewer-pass cap becomes per-complexity and configurable: 1 for simple, 2 for moderate, 3 for complex.
